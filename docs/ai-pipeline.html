What Each Stage Actually Does

The engineering decisions that make the pipeline reliable, fast, and cheap.

Stage 02 · Generation

Sonnet, brand-locked

The system prompt enumerates every void MJML tag, gives correct-vs-wrong examples, and injects the selected brand kit (colors, fonts, tone descriptors, disclaimer) ahead of the brief.

Brand identity is not a guideline — it is an input to every call. The model cannot generate off-brand because it never sees a brand-free prompt.

Stage 03 · Validation

Strict MJML or retry

The backend shells out to mjml --config.validationLevel=strict and parses errors. Common defects (orphan close-tags, void-tag wrappers) are auto-repaired before raising.

Hard failures trigger a retry with diagnostics: the original prompt is reissued with the validator's error report appended. Bad output never reaches the canvas.

Stage 05 · Refinement

Haiku, surgical edits

Refinement is a conversation, not a regeneration. The current MJML and the chat history are sent with each turn; Haiku returns the edited tree.

Median 2 turns to ship-ready. Each turn is sub-second, validated, and saved as a new version — nothing is lost.

Why It Stays Cheap and Reliable

Three architectural decisions that keep the pipeline production-grade.

Cost

Prompt caching by default

Brand kit + MJML rules + system prompt are wrapped in a cache_control block on every call. The first request pays full price; every subsequent call in the same session reads from cache.

Result: ~80% cache hit rate end-to-end. Per-emailer LLM cost stays in the cents, not the dollars.

Reliability

Validator-driven retry

The MJML validator is the contract between LLM output and storage. No version is persisted unless validation passes.

On the rare hard failure, the retry attaches the structured error list to the next prompt. The model sees exactly what it got wrong — success rate climbs to ~99% within one retry.

Speed

Two-model strategy

Sonnet for the first draft — deeper reasoning, better adherence to brand voice, takes the latency hit once.

Haiku for every edit after — ~20× cheaper, sub-second turnaround, ideal for "tighten the subject line" loops.
